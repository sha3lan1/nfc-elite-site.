NFC ELITE — Static website

Contents
- index.html: complete responsive Arabic website, CSS motion, WhatsApp ordering links, and product-photo examples.

Images
- Product photos are linked from Pexels and load from the internet.
- The printed brand names (NOVA STUDIO, CEDAR & CO., ATELIER NORTH, NFC ELITE) are HTML/CSS sample overlays, not edits to the original stock photos.
- Pexels says its photos are free for commercial use, but avoid implying that depicted brands endorse your shop and review current terms before launch.

Free publishing (GitHub Pages)
1. Sign in to GitHub and create a NEW public repository named nfc-elite-site.
2. Upload index.html to the repository root (and this README if desired).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Wait a few minutes and open the URL shown in Settings > Pages.

The site is static and has no paid backend. WhatsApp orders open a chat; it does not process payments or store orders.
